What is Playwright?

In plain QA words

Playwright is a tool that opens a browser, performs user actions, and checks the expected result. Think of it as a repeatable manual test that can run by itself.

The basic pattern

  1. Open the page.
  2. Find the right element.
  3. Do an action.
  4. Check the reaction.

NBA example

Manual QA: choose West in the conference filter. Playwright: select West in the same dropdown. Expected result: only Western Conference teams remain visible.

1 Manual action

You click, type, select, or search like a real user.

2 Page reaction

The website changes: data filters, sorts, appears, or disappears.

3 Playwright check

The test confirms the expected result and reports pass or fail.

Manual QA steps

  1. Open the Teams section.
  2. Choose West in the Conference dropdown.
  3. Check that only Western Conference teams are visible.

Playwright steps

  1. Open the page.
  2. Find the dropdown by test id.
  3. Select the conference value.
  4. Count visible team cards.
  5. Assert that the result is correct.
